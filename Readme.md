An **Exploratory Data Analysis (EDA)** project that explores the world of **OTT platforms** (Netflix, Amazon Prime, Disney+, Hulu, etc.) to uncover **content trends, audience preferences, and platform strategies**.  
Through insightful visualizations and statistical analysis, this project transforms raw data into meaningful insights.

---

## 🚀 Project Overview

With OTT platforms dominating entertainment, understanding **content patterns** has become essential.  
This EDA answers key questions like:
- Which platform has the largest content library?
- Are movies or TV shows more common?
- How have content trends evolved over the years?
- What genres dominate each platform?
- How do IMDb ratings vary between platforms?

---

## 📂 Dataset

- **Source**: Publicly available OTT dataset (Kaggle or other open sources)
- **Columns include**:
  - Title
  - Genre
  - Release Year
  - IMDb Rating
  - Type (Movie / TV Show)
  - Platform Availability
  - Country of Production

---

## 🛠️ Tools & Libraries

- **Python**
- **Pandas** – Data cleaning & analysis
- **NumPy** – Numerical computation
- **Matplotlib** – Static visualizations
- **Seaborn** – Statistical visualizations
- **Plotly** – Interactive charts
- **Jupyter Notebook** – Development environment

---

## 📊 Key Insights

📌 Some highlights from the analysis:
- 🎥 **Netflix** dominates in number of movies, while **Prime Video** leads in TV shows.
- ⭐ Higher IMDb ratings are often found in niche or regional content.
- 📅 OTT-exclusive releases surged after 2015.
- 🌍 Non-English content is gaining significant traction globally.
